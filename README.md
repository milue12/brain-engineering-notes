# Intro Brain Engineering

## 프로젝트 소개

이 저장소는 뇌공학 입문 과목에서 학습한 내용을 정리한 저장소입니다.

뇌 신호 측정, 뇌 자극 기술, 뇌-컴퓨터 인터페이스 등 뇌공학의 기초 개념을 정리하는 것을 목표로 합니다.

## 주요 학습 내용

- EEG, fMRI 등 뇌 신호 측정 기술
- tES, TMS 등 뇌 자극 기술
- 뇌-컴퓨터 인터페이스(BCI)
- 뇌공학의 응용 분야
